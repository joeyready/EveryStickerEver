A SMALL IDEA. A LOT OF SPREADSHEETS.

All 50 states.
All the combinations.
Absolutely no chill.

It started with a simple format: “Don’t [State] My [State].” Then came the math. Every state paired with every other state (including itself), then three color variations for each design. The result? A catalog that needed a little automation to exist.

04 / THE PROJECT

Not just stickers.
A production system.

Every Sticker Ever is an independent creative-automation project exploring what happens when a simple visual idea meets a very large set of data. It brings together graphic design, image production, scripting, and ecommerce catalog generation.

THIS IS A PORTFOLIO / EXPERIMENTAL PROJECT. THE STICKERS ARE NOT CURRENTLY FOR SALE (YET!).
